# Topic: modules

## Overview
The Glucose Module is the core health data component responsible for tracking, validating, and analyzing patient glucose levels.

## Key Concepts
- Glucose Readings (CGM, SMBG, MANUAL)
- Meal Context (Fasting, Bedtime, etc.)
- TIR (Time In Range) Calculation
- eHbA1c Estimation
